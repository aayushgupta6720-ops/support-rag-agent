# Two-Factor Authentication (2FA)

You can enable 2FA under Account > Security using an authenticator app (we
support any TOTP-compatible app, such as Google Authenticator or Authy). SMS
based 2FA is not supported.

When you enable 2FA, we generate 10 single-use backup codes. Store these
somewhere safe — they're the only way back into your account if you lose
access to your authenticator app. Each backup code can only be used once,
and you can regenerate a fresh set at any time from the Security page.

If you lose both your authenticator app and your backup codes, account
recovery requires manual identity verification through support, which can
take up to 3 business days.

Disabling 2FA requires entering a current code from your authenticator app
or a backup code; you cannot turn it off from a session that hasn't
completed 2FA.
